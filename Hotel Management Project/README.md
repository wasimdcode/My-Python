📌 What is WOYO?
WOYO is a simple desktop hotel booking application built with 💻 **Python** and **Tkinter**. It's designed to collect user booking information like name, contact, dates, room type, and special requests — then display it neatly, save it as a file, and even generate a cool QR code with all the details! 🔍📤

Perfect for a student project to impress teachers, friends, or maybe even yourself 😉

💡 Features
✔️ Clean and easy-to-use interface  
✔️ Booking form with all essential fields  
✔️ Unique Booking ID for each reservation  
✔️ Summary window to review details  
✔️ Save booking as PDF or text file 📄  
✔️ Auto-generated QR code with booking info 🔳  
✔️ No database required — it’s all local!

🛠️ How to Run
If you're using the `.exe` version:
1. Just double-click the `WOYO.exe` file  
2. No need to install Python 🐍  
3. Make sure the `wOYO.png` logo is in the same folder (important!)

If you're using the Python version:
```bash
python first.py
```
